# 真实数据验证计划（v0.7.2 / 任务 P0-06 要求 5、6）

> ## 当前状态：`NOT PERFORMED`
>
> 本版本**没有**附带任何已获再分发许可的实验谱数据集，因此**真实数据上的
> 鉴定准确率未经验证**。
>
> 本文件是一份**设计文档**，不是验证结果。在按本文件执行并记录结果之前，
> 不得在任何发布说明、README 或宣传材料中声称真实数据准确率。

---

## 1. 为什么现在做不了

| 阻碍 | 说明 |
| --- | --- |
| 许可 | MassBank、NIST、MetaboLights、GNPS 等数据集各有再分发条款。把实验谱**打包进仓库**通常不被允许，需要逐库核对。 |
| 规模 | 真实评测需要数百到数千条实验谱，且需人工核验的身份标签。 |
| 仪器异质性 | 不同仪器/碰撞能量/LIMS 配置下的谱图分布差异极大，需要按平台分层的评测协议。 |
| 诚实性 | 用「数据生成器生成的答案」冒充真实世界验证，正是任务书 1.1 明令禁止的行为。 |

因此本版本的选择是：**明确标记为未完成，而不是用合成结果替代。**

## 2. 数据来源候选与许可要求

按「获取难度 × 科学价值」排序：

| 候选数据集 | 内容 | 许可 | 可否随包分发 | 备注 |
| --- | --- | --- | --- | --- |
| **GNPS**（公共库子集） | 实验 MS/MS 谱 | CC0 / 部分 CC-BY | 需逐条核对 | 首选：许可最宽松 |
| **MassBank EU / JP** | 实验 MS/MS 谱 | CC-BY(-SA) 类 | 通常**不可**再分发，可运行时下载 | 需保留归属 |
| **NIST MS/MS** | 实验谱库 | 商业许可 | **否** | 需用户自备许可证 |
| **MetaboLights / Metabolomics Workbench** | 研究级原始数据 | 各研究自定 | 视研究而定 | 适合内部验证 |
| **用户自有数据** | 客户仪器数据 | 用户所有 | **否**（不入库） | 最贴近实际使用场景 |
| **内部实验数据** | 合作实验室测量 | 需书面授权 | 视授权而定 | 价值最高，门槛最高 |

**采集原则**：

- 每条记录必须记录：数据集 ID、来源 URL、版本/快照日期、许可证、获取方式、SHA-256。
- **来源不明的数据不得自动赋予开放许可证**（任务书 P1-05 要求 5）。
- 许可不允许再分发的数据集，只提供**运行时下载脚本与校验哈希**，不入库、不随包。

## 3. 验证设计

### 3.1 分层协议

| 层 | 数据 | 目的 | 指标 |
| --- | --- | --- | --- |
| L0 | 合成（现有） | 排名管线正确性与确定性 | 现有指标 |
| **L1** | 公开实验谱，**身份可靠**（标准品，有 CAS） | 真实准确率基线 | Top-1/3/5、MRR、置信度校准 |
| **L2** | 公开实验谱，**来源混合**（多仪器/多能量） | 仪器异质性下的鲁棒性 | 按仪器分层的准确率差异 |
| **L3** | 内部实验数据（如有授权） | 贴近真实使用 | 同上 + 失败案例人工复核 |

### 3.2 数据划分

- **参考库**与**查询谱**必须来自**不同来源**（避免闭环）。
- 若同一数据集同时提供参考与查询，需按化合物 ID 做**严格互斥划分**。
- 划分结果与随机种子必须落盘，保证可复现。

### 3.3 必须报告的项

1. 数据集名称、版本/快照日期、许可证、SHA-256。
2. 每个子集的样本数（参考库条目数、查询谱条数、化合物数）。
3. 每个指标的定义与计算方式（与 `V07_2_SYNTHETIC_BENCHMARK.md` 第 3 节保持一致）。
4. **置信度校准**：可靠性图（reliability diagram）与 ECE，因为现有基准已暴露
   置信度未校准的问题。
5. **失败案例分析**：至少列出所有 Top-5 未命中的查询谱及其谱图特征。
6. 仪器/碰撞能量分层结果。
7. 与合成基准的**差距**，并解释差异来源。

### 3.4 必须设置的阴性对照

- 错配证据（沿用现有 discrimination 对照）；
- 库外分析物（沿用现有 open-set 对照），并**新增拒绝阈值**的评估；
- 随机排名基线（Top-K 期望值）；
- 参考文献中同类方法在**同数据集**上的报告值（只在确实同数据集时比较）。
