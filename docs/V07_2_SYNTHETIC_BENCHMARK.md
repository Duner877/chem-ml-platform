> 鉴定准确率。**

## 1. 基准身份

| 项目 | 值 |
| --- | --- |
| 基准名称 | Identification known-answer benchmark |
| 基准类型 | **synthetic**（合成） |
| 脚本 | `scripts/benchmark_lcms.py` |
| 数据集版本 | `chemml-lcms-synthetic-2026.1` |
| 分析物来源 | `databases.local_library.COMPOUND_LIBRARY`，**24** 个化合物 |
| 加合物 | `[M+H]+` |
| 质量容差 | 15 ppm（所有配置固定不变，唯一变量是证据通道组合） |
| 样本数 | **24 用例 × 2 参考库 × 5 配置 = 240 次评测** |
| 运行耗时 | 约 2.9 s |
| 是否使用真实仪器数据 | **否** |
| 原始指标 | `output/benchmark_lcms.json`（含 `provenance` 段） |

### 1.1 为什么必须标注为合成

任务书 1.1 明确要求「**不以合成数据基准代替真实科研验证**」，P0-06 要求
「将现有合成基准明确命名为 synthetic benchmark」。

因此：

- 脚本启动时打印醒目的合成基准横幅；
- **机器可读输出中携带 `provenance` 段**（`benchmark_kind` / `real_instrument_data` /
  `real_data_validation` / `forbidden_claims` / `permitted_claims`）；
- 下游报告**无法**在不携带该声明的情况下引用这些数字。

## 2. 两套参考库的性质（关键区别）

| | `synthetic` 参考库 | `curated` 参考库 |
| --- | --- | --- |
| 参考值来源 | 平台自身正向模型（`models.spectra`） | 仓库内**手写**诊断性数值（`databases.local_library`） |
| 与评分模型独立 | **否**（闭环） | 是（参考值不由同一正向模型产生） |
| 分子身份是否真实 | 是（公式/SMILES/单同位素质量） | 是，**并与 PubChem 数值核对** |
| 是否来自已授权实验谱库 | 否 | **否** |
| 能证明什么 | 排名管线能复现已知答案 + 确定性 | 参考值与评分模型不同源时排名仍稳定 |
| **不能**证明什么 | 任何真实世界准确性 | 任何真实仪器准确性 |

> **诚实更正**：v0.7.1 的说明把 `curated` 描述为「经验性 / empirical」参考值，
> 容易被读成「来自真实测量」。事实是这些谱峰位置由本项目手写维护，仅分子身份
> 与 PubChem 核对。v0.7.2 已在脚本 docstring、运行横幅与机器可读输出中改正。

## 3. 指标定义与计算方法

| 指标 | 定义 | 计算方式 | 样本数 |
| --- | --- | --- | --- |
| Top-1 accuracy | 正确答案排名第 1 的比例 | 命中数 / 24 | 24 |
| Top-3 accuracy | 正确答案在**前 3** 名内的比例 | 命中数 / 24 | 24 |
| Top-5 accuracy | 正确答案在**前 5** 名内的比例 | 命中数 / 24 | 24 |
| MRR | 正确答案排名的倒数均值 | `mean(1/rank)` | 24 |
| mean confidence | 首选候选的置信度均值 | `mean(conf)` | 24 |
| discrimination rate | 正确候选对自身证据的得分高于对**轮换错配**证据得分的比例 | 命中数 / 24 | 24 |
| determinism | 两次独立运行排名是否**逐字节相同** | 布尔 | 24 |
| open-set confidence | 库外分析物（香兰素）首选候选的置信度 | 单次 | 1 |

**评测配置（每个参考库各跑一遍）**：`ms_only`、`ir_only`、`nmr_only`、`uv_only`、
`multimodal`（四通道融合）。

## 4. 实测结果

### 4.1 synthetic 参考库（闭环）

| 配置 | Top-1 | Top-3 | Top-5 | MRR | mean conf |
| --- | --- | --- | --- | --- | --- |
| ms_only | **1.000** | 1.000 | 1.000 | **1.000** | 0.955 |
| ir_only | 0.375 | 0.667 | 0.792 | 0.545 | 1.000 |
| nmr_only | 0.542 | 0.875 | 0.958 | 0.713 | 1.000 |
| uv_only | 0.083 | 0.333 | 0.500 | 0.276 | 1.000 |
| **multimodal** | **1.000** | **1.000** | **1.000** | **1.000** | 0.975 |

### 4.2 curated 参考库（参考值与评分模型不同源）

| 配置 | Top-1 | Top-3 | Top-5 | MRR | mean conf |
| --- | --- | --- | --- | --- | --- |
| ms_only | 0.917 | 0.917 | 0.917 | 0.921 | 0.535 |
| ir_only | 0.167 | 0.500 | 0.542 | 0.340 | 0.778 |
| nmr_only | 0.542 | 0.875 | 0.958 | 0.713 | 1.000 |
| uv_only | 0.042 | 0.167 | 0.250 | 0.158 | 0.417 |
| **multimodal** | **0.917** | **0.917** | **0.917** | **0.927** | 0.682 |

**可以从中读出的结论**（仅限于合成条件）：

- 单通道中质谱贡献最大；UV 单独使用几乎无判别力。
- 四通道融合后 Top-1 不低于最强单通道。
- 参考值与评分模型不同源时，融合后的 Top-1 从 1.000 降到 0.917，
  说明该基准**确实对来源差异敏感**——这正是一个基准应有的性质。
- `curated` 库 `nmr_only` 的置信度恒为 1.000，说明该通道在参考值不完全一致时
  **置信度校准偏乐观**。这是一个**未被修复的已知局限**，不应忽略。

### 4.3 阴性对照

| 对照 | 结果 | 说明 |
| --- | --- | --- |
| discrimination rate | **1.000**（匹配 0.9754 vs 错配 0.2997，分离度 0.6756） | 正确候选对自身证据的得分系统性高于错配证据 |
| determinism | **identical** | 两次独立运行排名逐字节相同 |
| open-set（香兰素） | 置信度 **0.512**（被误判为 paracetamol），远低于闭环 0.975 | 库外分析物不会被赋予库内级别的置信度 |

> open-set 对照**暴露了一个真实弱点**：库外分析物仍会被给出 0.51 的置信度并返回一个
> 具体候选。当前只保证「显著低于库内」，**没有**实现「拒绝鉴定」机制。

## 5. 回归阈值与对外宣传指标的分离

任务书 P0-06 要求 4：**将回归阈值与对外宣传指标分开**。

### 5.1 这些阈值是回归门禁，不是性能声明

`THRESHOLDS` 中的每个值都**刻意设在实测值之下**，目的是在出现真实回退时报警，
而不是用来描述系统能力。

| 阈值键 | 门禁值 | 实测值 | 性质 |
| --- | --- | --- | --- |
| `synthetic.multimodal.top1` | 0.90 | 1.000 | 回归下限 |
| `synthetic.multimodal.top3` | 1.00 | 1.000 | 回归下限（不允许任何回退） |
| `synthetic.multimodal.mrr` | 0.95 | 1.000 | 回归下限 |
| `synthetic.ms_only.top1` | 0.90 | 1.000 | 回归下限 |
| `curated.multimodal.top1` | 0.75 | 0.917 | 回归下限 |
| `curated.multimodal.top3` | 0.90 | 0.917 | 回归下限 |
| `discrimination.rate` | 0.80 | 1.000 | 回归下限 |
| `discrimination.separation` | 0.05 | 0.676 | 回归下限 |

**禁止的解读**：把门禁值（0.90 / 0.75）当成「平台准确率」对外宣传。
门禁值只表示「低于此值即判定为回退」。

### 5.2 允许与禁止的表述

**允许**（有证据支持）：

- 「在合成数据上，四通道融合能够复现 24 个已知答案，Top-1 = 1.000。」
- 「参考值与评分模型不同源时，Top-1 仍为 0.917。」
- 「两次独立运行排名完全一致。」
- 「库外分析物的置信度显著低于库内化合物。」

**禁止**（无证据支持）：

- ❌「LC-MS/MS 鉴定准确率达到 91.7%。」
- ❌「多模态融合鉴定准确率 100%。」
- ❌ 与文献报告的真实数据集准确率直接比较。
- ❌ 把合成基准当作「真实科研验证已完成」的证据。

上述禁止项同时以**机器可读形式**写入 `output/benchmark_lcms.json` 的
`provenance.forbidden_claims`，便于自动化检查。

## 6. 已知局限

| 局限 | 影响 | 状态 |
| --- | --- | --- |
| 无真实仪器数据 | 真实世界准确率完全未知 | **已知，未解决**（见验证计划） |
| `curated` 谱峰为手写值 | 不代表任何真实谱库的统计特性 | 已知，已在文档与输出中标注 |
| `curated` / `nmr_only` 置信度恒为 1.000 | 置信度未校准 | 已知，未解决 |
| open-set 无拒绝机制 | 库外分析物仍被赋予候选与置信度 | 已知，未解决 |
| 24 个化合物 | 样本量小，统计不确定性大 | 已知 |
| 分子量范围有限 | 未覆盖高分子量 / 多电荷 / 同分异构体密集区 | 已知 |

## 7. 复现方式

```bash
# 打印完整表格
python scripts/benchmark_lcms.py

# 输出机器可读结果（含 provenance）
python scripts/benchmark_lcms.py --json output/benchmark_lcms.json

# 质量门禁用（阈值不满足则非零退出）
python scripts/benchmark_lcms.py --strict
```

质量门禁阶段 `benchmark_tests` 与 `synthetic_benchmark`，以及发布流水线阶段 6，
都以 `--strict` 执行本脚本；任一阈值不满足即使流水线失败。
