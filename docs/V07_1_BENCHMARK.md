# 鉴定工作流已知答案基准（v0.7.1）

> 对应任务书 §五 与任务 I「至少一个端到端工作流有已知答案基准」。
> 执行脚本：`scripts/benchmark_lcms.py`（无网络依赖，全部使用内置引擎）
> 原始指标：`output/benchmark/lcms_benchmark.json`

## 1. 目的与范围

v0.7.1 是安全修复与工程完备版本，**不以增加节点数量为目标**。本基准用于证明
「未知物结构鉴定」这一旗舰工作流在**已知答案**上的真实表现，并提供可复现、
可回归的质量红线。

- 被测对象：`UnknownCompoundIdentificationNode`（多通道证据融合鉴定节点）。
- 被测数据：`databases/local_library.py` 中 24 个化合物，分子式、单同位素质量、
  SMILES 均为已知真值；参考库目录结构见 `datasets/README.md`。
- 评测集规模：24 个已知样本 × 2 套参考库；任务书建议 50–100 个「以可验证的
  数据来源和质量为准」，当前离线库为 24 个经核验化合物，规模受**可核验来源**
  限制而非人为设定，已如实记录于 `V07_KNOWN_LIMITATIONS.md`。

## 2. 方法：两套参考库

为避免「用模型验证模型」导致数字虚高，基准同时评估两套参考库：

| 参考库 | 观测谱来源 | 参考条目来源 | 含义 |
| --- | --- | --- | --- |
| `synthetic` | 内置正向模型 + 噪声 | **同一**正向模型 | 闭环检查：验证「检索/排序流水线」能否复现已知答案，并兼作确定性测试 |
| `curated` | 内置正向模型 + 噪声 | 库中**经验/文献**诊断碎片、IR 谱带、UV 最大吸收 | 跨来源检查：参考库并非由同一模型生成时的真实鲁棒性 |

每个化合物都会生成一路「未知样品」证据（LC-MS/MS 前体与碎片、IR、¹H NMR、UV），
再送入鉴定节点，在**候选库（含全部 24 个化合物）**中排序，判定真值化合物的名次。

质量容差固定 `15 ppm`，`[M+H]+` 加合，结果缓存关闭；正向模型为确定性实现，
基准对全部正向预测做进程内记忆化以保证 15 秒内可重复运行（不改变任何数值）。

## 3. 结果

### 3.1 闭环参考库（`synthetic`）

| 配置 | Top-1 | Top-3 | Top-5 | MRR | 平均置信度 |
| --- | --- | --- | --- | --- | --- |
| MS only | **1.000** | 1.000 | 1.000 | 1.000 | 0.955 |
| IR only | 0.375 | 0.667 | 0.792 | 0.545 | 1.000 |
| NMR only | 0.542 | 0.875 | 0.958 | 0.713 | 1.000 |
| UV only | 0.083 | 0.333 | 0.500 | 0.276 | 1.000 |
| **多模态融合** | **1.000** | **1.000** | **1.000** | **1.000** | 0.975 |

### 3.2 跨来源参考库（`curated`）

| 配置 | Top-1 | Top-3 | Top-5 | MRR | 平均置信度 |
| --- | --- | --- | --- | --- | --- |
| MS only | 0.917 | 0.917 | 0.917 | 0.921 | 0.535 |
| IR only | 0.167 | 0.500 | 0.542 | 0.340 | 0.778 |
| NMR only | 0.542 | 0.875 | 0.958 | 0.713 | 1.000 |
| UV only | 0.042 | 0.167 | 0.250 | 0.158 | 0.417 |
| **多模态融合** | **0.917** | **0.917** | 0.917 | 0.927 | 0.682 |

### 3.3 阴性对照

| 对照 | 结果 |
| --- | --- |
| 判别力（匹配 vs 错配证据） | 匹配 0.975 / 错配 0.300，判别率 **1.000**，分离度 **0.676** |
| 确定性（两次独立运行） | 排序**逐字节一致** |
| 开放集（库外分析物 vanillin） | Top-1 置信度 **0.512** < 闭环 0.975 |

## 4. 判读

1. **流水线正确性成立**：闭环下 MS-only 与多模态融合 Top-1 均为 1.000，
   说明前体质量过滤 → 碎片/多通道打分 → 加权归一化的链路能够稳定复现已知答案。
2. **融合确实带来增益**：单通道 IR / UV 的 Top-1 仅 0.375 / 0.083，融合后升至 1.000，
   证明多通道加权不是装饰。
3. **跨来源退化是真实且被如实记录的**：参考库换成经验碎片后，多模态 Top-1 从
   1.000 降到 **0.917**（2/24 失败）。这是诚实结果，未做任何掩饰。
4. **阴性对照全部通过**：节点在证据错配时置信度显著下降（0.975→0.300），
   对库外分析物不给出高置信匹配（0.512），且完全确定性可复现。

## 5. 已知失效案例（`curated` 多模态）

| 化合物 | 真值名次 | 被误报的 Top-1 | 原因 |
| --- | --- | --- | --- |
| nicotine (C₁₀H₁₄N₂) | 8 | dopamine (C₈H₁₁NO₂) | 库中经验碎片与吡啶/胺类化合物高度重叠，经验碎片对本例判别力不足 |
| histidine (C₆H₉N₃O₂) | 8 | L-tryptophan (C₁₁H₁₂N₂O₂) | 咪唑与吲哚在经验 IR 谱带（1600 cm⁻¹ 区间）上难以区分 |

> 上述两例在**闭环**参考库下均能正确排序第一，说明缺陷来自「经验参考库判别力」
> 而非算法本身。这属于数据集/参考库的固有限制。

## 6. 置信度标定问题（如实记录）

单通道配置下 `平均置信度` 常等于 **1.000**，但 Top-1 很低（如 IR only 0.375）。
原因：当仅有单一通道可用时，节点在所有候选上只用该通道归一化，最高分者恒为 1.0，
**置信度并不反映跨候选的区分度**。多模态下由于权重分布到多个通道，该问题被稀释
（闭环平均 0.975，跨来源 0.682）。

结论：**v0.7.1 的置信度在单通道场景下未做跨候选标定**，不能直接当作「概率」使用。

## 7. 与软件测试、数值验证的区分（任务 I.4）

| 层级 | 含义 | 本基准中的体现 |
| --- | --- | --- |
| 软件测试 | 代码路径、接口、异常处理 | `tests/test_v07_1_benchmark.py`（快速回归子集） |
| 数值验证 | 算法在受控输入下数值正确 | 闭环 `synthetic` 参考库指标、确定性检查 |
| 科学结果验证 | 对真实测量数据的科学结论 | **未完成**——当前样本由平台正向模型生成，非独立实验数据，已标注为局限 |

## 8. 质量红线（`--strict` 模式）

`scripts/benchmark_lcms.py --strict` 在下列任一项不满足时返回非零退出码，
并被 `scripts/quality_gate.py` 的 `check_scientific_benchmark` 调用：

| 指标 | 阈值 |
| --- | --- |
| 闭环多模态 Top-1 | ≥ 0.90 |
| 闭环多模态 Top-3 | ≥ 1.00 |
| 闭环多模态 MRR | ≥ 0.95 |
| 闭环 MS-only Top-1 | ≥ 0.90 |
| 跨来源多模态 Top-1 | ≥ 0.75 |
| 跨来源多模态 Top-3 | ≥ 0.90 |
| 判别率 | ≥ 0.80 |
| 置信度分离度 | ≥ 0.05 |
| 确定性 | 两次运行完全一致 |
| 开放集 | 置信度低于闭环 |

阈值均设置于实测值之下留出回归余量，但高于「随机」水平，可捕捉真实退化。

## 9. 复现

```bash
python scripts/benchmark_lcms.py                       # 打印全部指标
python scripts/benchmark_lcms.py --json out.json       # 导出原始指标
python scripts/benchmark_lcms.py --strict              # 不达标则非零退出
python -m pytest tests/test_v07_1_benchmark.py         # 快速回归子集
```

典型运行时间：约 15 秒（24 用例 × 2 套参考库 + 阴性对照）。
