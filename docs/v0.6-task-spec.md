# Chem ML Platform v0.6 — Scientific Foundation Model Edition · 任务书

> 基线：v0.5.3 Research Ready（85 节点 / 27 分类 / 5 Demo / 43 测试）
> 原则：**不删除任何已有功能**；所有新增代码必须可直接运行（零伪代码）；依赖方向只能向下。

## 0. 版本主题

v0.5.x 把平台从「节点计算器」提升为「研究工作流引擎」。v0.6 的主题是
**统一科学基座模型（Scientific Foundation Model）**：把分散在
`models/`、`nodes/ai/foundation.py`、`ai_runtime/` 里的分子表征、性质预测、
谱学解释能力，收敛成一个**统一的、可被 Agent 与 GUI 直接调用的基座模型运行时**，
并让**云端 / 本地大模型可运行时切换**，最终由**可运行的 Agent** 编排成自主科研闭环。

四层同心结构：

```
        ┌───────────────────────────────────────────────┐
        │  Agent Runtime（可运行：CLI / REST / GUI）      │
        ├───────────────────────────────────────────────┤
        │  Foundation Runtime（统一科学基座模型）         │
        ├───────────────────────────────────────────────┤
        │  AI Runtime（Cloud / Local / Offline 可切换）   │
        ├───────────────┬───────────────┬───────────────┤
        │ Data Layer    │ Simulation    │ Workflow      │
        │ (Catalog)     │ Runtime(Jobs) │ Engine(Nodes) │
        └───────────────┴───────────────┴───────────────┘
```

## 1. 优先保证的 5 项能力

### 1.1 Agent 可运行（最高优先级）
- 提供独立 CLI：`python scripts/run_agent.py "问题"`，零配置即可跑通（规则规划器 + 离线推理）。
- 提供 REST：`POST /api/agent/ask`、`GET /api/agent/history`、`POST /api/agent/plan`。
- 规划器接入 `ai_runtime.complete`：配置了 LLM 就用 LLM 规划，否则自动回退规则规划器，并在结果里标注 `engine`。
- GUI 提供 Agent 面板：输入问题 → 展示计划 → 展示工作流 → 展示结论报告。

### 1.2 Cloud / Local AI 切换
- 新增 `ai_runtime/config.py`：`AIConfig(mode, provider, model, keys, base_urls, temperature, max_tokens)`。
- `mode ∈ {auto, cloud, local, offline}`；`auto` 按 cloud→open_source→chemistry→local→offline 顺序回退。
- 配置持久化到 `config/ai.json`，并支持 `CHEMML_AI_MODE` 环境变量覆盖。
- REST：`GET /api/ai/providers`、`GET /api/ai/config`、`PUT /api/ai/config`、`POST /api/ai/complete`。
- GUI 提供 AI 设置面板：供应商可用性、模式切换（云端 / 本地 / 离线 / 自动）、模型与温度。

### 1.3 Scientific Data Layer
- 新增 `data_layer/catalog.py`：把 `ingest()` 产出的 `ScientificDataObject` 编目成持久目录（`output/catalog/catalog.json`）。
- 支持 `add / search / get / stats`，并可为条目附加基座模型嵌入向量（`foundation.embed`）。
- REST：`POST /api/data/ingest`、`GET /api/data/catalog`、`GET /api/data/catalog/{id}`。
- GUI 提供数据面板：编目列表、关键词检索、一键入库。

### 1.4 Simulation Runtime
- 新增 `simulation_runtime/jobs.py`：线程化作业管理器，包装既有 `runtime.run(family, system, backend)`。
- 支持 `submit / list / get`，记录 `engine`（`external:<exe>` / `internal:<engine>`）、状态、耗时、产物。
- REST：`GET /api/simulations/backends`、`POST /api/simulations/run`、`GET /api/simulations/jobs`。
- GUI 提供模拟监控面板：后端可用性、提交作业、作业历史。

### 1.5 GUI 升级
- 右侧改为**分页工作台 Dock**：`检查器 | AI | Agent | 数据 | 模拟`。
- 新增 4 个面板，全部接入上面的 REST（真实数据，非占位）。
- 品牌升级到 v0.6，空状态文案更新。

## 3. 验收标准

1. `python -m pytest tests/` 全绿，且新增测试覆盖 foundation / ai 配置 / catalog / jobs / agent。
2. `python scripts/smoke_nodes.py --quiet` 仍为全绿（节点数 ≥ 85）。
3. `python scripts/run_demo_workflows.py` 全绿（≥ 6 个 Demo）。
4. `python scripts/run_agent.py "..."` 零配置输出计划 + 结论。
5. `cd frontend && npm run build` 通过。
6. `cd node_sdk/nodejs && npm test` 通过。
7. `python scripts/package.py` 产出 `Chem-ML-Platform-v0.6.0.zip`。
