# XAS-Sim2Real：双向 XANES 谱域映射

在统一能量网格上完成两种**谱到谱**映射，不做结构反演与物相判定。

| 方向 | 输入 | 输出 |
| --- | --- | --- |
| `sim2exp` | 标准化 Materials Project 模拟谱 | 标准化实验谱 |
| `exp2sim` | 标准化实验谱 | Materials Project 模拟域表示 |

---

## 1. 快速使用

赛题规定的接口：

```bash
python /root/solution.py --input queries.npz --output predictions.npz
```

`predictions.npz` 只含两个数组：

- `sample_id`：与查询集合完全一致，每个 ID 恰好出现一次；
- `prediction`：形状 `(N, 133)`，全部有限，强度绝对值不超过 `1e6`。

可选参数：

| 参数 | 说明 |
| --- | --- |
| `--paired PATH` | 指定公开配对训练数据 NPZ |
| `--verbose` | 进度与诊断输出到 stderr |

未显式给出 `--paired` 时，会在输入同目录、`./data` 与 `/root/environment/data`
下依次查找 `paired_train.npz` / `train.npz` / `xas_pairs.npz`。

---

## 2. 方法：恒等映射 + 残差修正

两个域共享同一套电子结构，差别是一组**系统性、逐能量点分辨**的畸变——
线站展宽、小的能量零点位移、增益与尺度差。因此模型不从零生成目标谱，而是

```
target ≈ source + correction( source 的形状, 吸收元素, 吸收边 )
```

**为什么必须是残差学习。** 在带已知畸变的合成数据上实测：

| 方案 | 逐点 MAE |
| --- | --- |
| 直接回归目标谱 | 0.280 |
| 恒等映射（原样返回源谱） | 0.053 |
| 目标均值基线 | 0.034 |
| **恒等 + 残差修正（本实现）** | **0.026** |

直接从零回归比"什么都不做"差了 5 倍——它在破坏一个本就几乎正确的答案。
残差学习把恒等映射设为零点，模型只可能在此之上改善，这也是小样本下唯一
合理的行为。实测收益 **13 倍**。

残差由两部分给出，按 `0.5 / 0.5` 混合：

- **岭回归**（闭式解，纯 NumPy）承担全局趋势；
- **k 近邻残差平均**（k=5，按距离倒数加权）保护白线这类尖锐结构，
  避免全局线性映射把它抹平。

注意 k-NN 平均的是**邻居的残差**而非目标曲线：平均曲线会把答案拖向训练均值，
丢掉查询自身的形状。

## 3. 特征

每条谱压成 35 维描述子，分三族：

1. **形状摘要**——白线高度与位置、pre-edge 本底、边跳、post-edge 斜率与振荡幅度。
   这些正是从 XANES 曲线上直接读出的量，也是必须跨域传递的量。
2. **24 个粗采样点**——保留足够形状信息让岭回归能定位曲线，又不把 133 点
   全塞给小样本岭回归。
3. **条件**——吸收元素 Z 与吸收边码，使模型能学到逐元素/逐边的偏移，
   而不是强行共用一套映射。

距离与回归都在**同一标准化空间**内计算。混用标准化与原始距离会静默改变邻居
权重，这是第一版失效的直接原因。

---

## 4. 可靠性与外推标注

题目明确不要求置信区间，但要求区分"验证过的映射"与"外推"。每次预测都附带：

- `method`：实际使用的方法；
- `n_support`：配对支撑样本量；
- `nearest_distance`：最近邻距离；
- `extrapolating` 与文字说明。

外推判据有两个，都不是拍脑袋的常数：

- 最近邻距离超过**训练集自身留一距离的 95 分位**（由
  `support_distance_quantile()` 现场算出，不写死）；
- 查询吸收边类型未在训练数据中出现。

## 5. 契约与失败处理

| 情况 | 行为 |
| --- | --- |
| 输入文件缺失 | 退出码 **2** |
| 必需数组缺失（`sample_id` / `direction` / `spectrum`） | 退出码 **2** |
| 含 NaN / Inf | 退出码 **2** |
| 方向取值非 `sim2exp` / `exp2sim` | 退出码 **2** |
| 查询含重复 ID | 退出码 **2** |
| 训练数据缺失或不可读 | **降级为恒等映射**，仍输出完整合法文件 |
| 求解内部异常 | 退出码 **3** |

**不做静默伪造。** 输入不合法时宁可明确失败，也不产出外观合法、实则编造的
预测文件。

---

## 6. 确定性

全程无随机数：岭回归是闭式正规方程（`numpy.linalg.solve`，奇异时退化为
`lstsq`），近邻是精确距离计算，`argsort` 使用 `stable` 排序。

因此重复运行**逐位一致**（实测跨进程最大绝对差 `0.000e+00`），远严于题目要求的
`atol=1e-6, rtol=1e-5`。每次调用无状态，不依赖上一次的缓存或检查点。

岭惩罚按样本数缩放（`α · n`）而非固定绝对值——固定值会让收缩强度随配对集变小
而变强，对小样本任务是反效果的。

---

## 7. 性能与依赖

- 单次推理实测 **0.64 秒**，题目硬上限 300 秒；
- **纯 NumPy**，不引入 scikit-learn。打包桌面运行时只固定
  numpy / scipy / networkx / matplotlib / python-docx，加 scikit-learn 会让
  这个节点对目标用户直接不可用。

## 8. 平台节点

同一能力也作为工作流节点提供，可在 GUI 中编排：

**节点**：`XASSim2RealNode`（XAS 谱域映射，分类 `Instruments/Surface`）

| 端口 | 方向 | 说明 |
| --- | --- | --- |
| `spectrum` | 输入（可选，多值） | 待映射的源谱 |
| `prediction` | 输出 | 目标域预测谱（133 点） |
| `table` | 输出 | 逐点预测与修正量 |
| `text` | 输出 | 方法来源、支撑样本量、外推标记 |

参数：`direction`（`sim2exp` / `exp2sim`）、`absorbed_Z`、`edge_code`、
`paired_path`。

摘要中固定声明**不反演结构、不判定物相**，与题目的适用性边界保持一致。

---

## 9. 数据使用声明

- 训练仅使用 `environment/resources.yaml` 列出的公开配对数据；
- **不使用**隐藏配对、源数据目录、网络，也不通过文件名或材料 ID 推断目标谱；
- 不把 MP 结构库当作检索捷径——本方法是谱到谱映射，不是结构检索；
- `auxiliary_experiments.npz` **未用于**拟合。它只有实验谱、没有配对模拟谱，
  用作监督标签等于伪造模拟目标。可以用它做实验域自监督或稳健性诊断，
  但那不影响这里的映射精度，因此当前实现未引入，避免以任何方式污染评估。
